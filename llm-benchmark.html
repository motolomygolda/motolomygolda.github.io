Code Correctness Benchmarking & Failure-Mode Analysis for LLMs

  • Tech Stack: Python, OpenAI API, CodeLlama, Docker Sandbox, Statistical Evaluation
  • Research Area: Large Language Models, Software Engineering, Benchmarking

Designed and implemented a stratified benchmark of 90 Python programming tasks to systematically evaluate the code-generation capabilities of modern large language models.

Built an automated evaluation framework that executed 540 sandboxed test runs across GPT-3.5-Turbo and CodeLlama-7B-Instruct while measuring pass@1, pass@3, and bootstrap confidence intervals.

Developed a four-category failure taxonomy (syntactic, runtime, algorithmic, and edge-case failures) that provided deeper insight into why models fail rather than simply reporting accuracy.

The study showed that 90–100% of syntactic and runtime failures could be recovered through multi-sample aggregation, while algorithmic reasoning errors remained the primary challenge.
